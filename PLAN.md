# Project Plan — NetCtrl

> Generated by `/dev:scaffold-existing` on 2026-05-28
> Stack: Rust + ratatui + crossterm
> Type: Terminal TUI CLI tool

## Milestone 1: Core TUI & Logging

**Goal:** A fully functional terminal UI for managing amateur radio nets, sessions, and check-ins.
**Status:** Complete

### Features
- [x] Multiple saved nets with frequency, offset, PL tone, club/association
- [x] Multi-session logging per net with dated sessions
- [x] Digital net support with mode picker (20 modes) and notes
- [x] Check-in logging with automatic UTC timestamps
- [x] Callsign autocomplete from previous check-ins
- [x] FCC callsign lookup via callook.info
- [x] Operator profile (callsign + name)
- [x] Export session log to formatted text file
- [x] Resizable panels via keyboard shortcuts
- [x] Base16 theming with 8 built-in themes + custom theme support
- [x] Persistent JSON storage at `~/.netcontrol_data.json`

---

## Milestone 2: Scheduling & Automation

**Goal:** Allow scheduling future net sessions with a countdown alert that auto-opens the session.
**Status:** In Progress

### Features
- [ ] Scheduled net sessions with create-now vs schedule-later modal
- [ ] Persistent scheduled session storage
- [ ] 5-minute countdown alert overlay with diagonal stripes
- [ ] Auto-open session and add-checkin dialog when timer expires

- Startup time < 500ms
- Cross-platform terminal support via crossterm (primary target: Linux)
- JSON data forward-compatible via `#[serde(default)]`
