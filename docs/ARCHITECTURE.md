## Project Structure

```
netCtrl/
├── src/
│   ├── main.rs         # Entry point: terminal setup, event loop, tick timer
│   ├── app.rs          # App state: data, focus, list states, modal, theme
│   ├── models.rs       # Data types: Net, Session, CheckIn, KnownOp, AppData
│   ├── dialogs.rs      # Dialog structs and logic: NetDlg, CiDlg, SessionDlg, etc.
│   ├── input.rs        # Key event dispatch: modal handlers + main navigation
│   ├── ui.rs           # Rendering: layout, lists, modals, theme-aware styling
│   ├── theme.rs        # Base16 theme system: built-ins, custom TOML loading
│   └── persistence.rs  # JSON load/save, migration, ID generation
├── Cargo.toml
├── Cargo.lock
├── README.md
└── LICENSE
```

**Key conventions:**
- All UI state lives in `App.modal: Modal`; `input.rs` intercepts keys when modal is active
- Dialog structs hold their own field state and validation logic in `dialogs.rs`
- `save_data()` is called synchronously after every mutating action
- `persistence.rs` handles forward-compatible migration via `net.migrate()`
